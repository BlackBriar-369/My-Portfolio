## Local preview

Open `index.html` directly in a browser, or use VS Code Live Server.

Recommended:

1. Open this folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Click **Open with Live Server**.

## GitHub Pages upload

1. Create a new GitHub repository.
2. Upload all files and folders from this project.
3. Go to **Settings → Pages**.
4. Select the `main` branch and `/root` folder.
5. Save and wait for GitHub to publish the website.

## Notes

- The research poster opens in a JavaScript lightbox.
- Certificates also open in the same lightbox.
- The site uses professional system fonts, so it will load fast and does not depend on external font files.
- Review your phone number and email before making the website public.
